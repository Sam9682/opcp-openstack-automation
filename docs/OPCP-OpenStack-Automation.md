# OPCP OpenStack Automation - Présentation pour les Clients

## Introduction

Bienvenue dans l'offre d'automatisation OpenStack de PSMC OVH. Ce programme vous permet de découvrir comment automatiser les opérations sur OpenStack à l'aide de divers outils et frameworks modernes, dans un environnement sécurisé et pratique.

## Objectif de l'Offre

Cette formation vous permet de :
- Comprendre les concepts d'automatisation OpenStack
- Utiliser le SDK Python pour OpenStack
- Automatiser la configuration avec Terraform
- Expérimenter l'automatisation via SkillHub

## Public Cible et Profil

### Public Cible
- Administrateurs système souhaitant automatiser leurs opérations OpenStack
- Développeurs et ingénieurs IT intéressés par l'automatisation cloud
- Professionnels souhaitant maîtriser les outils d'automatisation OpenStack

### Profil Attendu
- Niveau technique intermédiaire
- Connaissance de base des concepts de cloud computing
- Capacité à utiliser un terminal/command line
- Familiarité avec les outils de développement de base
- Notions de Python et de scripting

## Durée Estimée

### Temps Total : 1 journée
- **Phase 1 : Introduction et Prérequis** (~1 heure)
- **Phase 2 : Concepts Fondamentaux** (~1 heure)
- **Phase 3 : Exercices Pratiques** (~2 à 3 heures)
- **Phase 4 : Résumé et Prochaines Étapes** (~1 heure)

## Prérequis Techniques

Avant de commencer, assurez-vous de disposer des éléments suivants :

### Environnement Local
- **Python 3.9+** (recommandé : 3.11)
- **Docker** (version 20.10 ou supérieure)
- **OpenStack CLI Client** (python-openstackclient)
- **Accès à un environnement OPCP/OpenStack**
- **Git** pour cloner le dépôt

### Outils Recommandés
- Terminal/Command Line (Linux/macOS/Windows WSL)
- Éditeur de texte (VS Code recommandé)
- (Optionnel) shai CLI (assistant IA terminal)

## Structure de l'Environnement de Formation

### 1. SkillHub - Formation Web Interactive
- Interface web multilingue (Français/English)
- Contenu structuré en modules pédagogiques
- Guide pas à pas pour chaque concept OpenStack
- Validation automatique des connaissances

### 2. Labs - Environnement de Pratique
- Connexion à un environnement OpenStack réel
- En option, containerisation complète avec Docker/Podman
- Exercices pratiques avec validation automatique
- Gestion sécurisée des ressources

## Modules de Formation

### Module 1 : Introduction à l'Automatisation OpenStack
- Présentation du SDK Python OpenStack
- Configuration de l'environnement de développement
- Premier script d'automatisation

### Module 2 : Automatisation avec le SDK Python
- Authentification et gestion des connexions
- Gestion des instances (Nova)
- Gestion des réseaux (Neutron)
- Gestion du stockage (Cinder)

### Module 3 : Automatisation avec Terraform
- Configuration des fichiers Terraform
- Déploiement d'infrastructures IaC
- Gestion des états et des variables

### Module 4 : Intégration et Orchestration
- Combinaison des outils d'automatisation
- Déploiement complet avec SkillHub
- Bonnes pratiques d'automatisation
